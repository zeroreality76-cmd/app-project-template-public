# Incidentrutin

1. Bekräfta symptom, tid, omfattning och påverkan utan att logga hemligheter eller onödig persondata.
2. Klassificera allvar, utse incidentägare och besluta om stoppa/isolera/rollback enligt rollbackplanen.
3. Spara faktiska bevis, beslut och tidslinje i ett risk- eller incidentärende.
4. Informera berörda enligt projektets kommunikationsplan.
5. Verifiera återställning, analysera rotorsak och skapa konkreta uppföljningar.
6. Uppdatera relevant säkerhets-, drift- och dokumentationsunderlag innan ärendet stängs.

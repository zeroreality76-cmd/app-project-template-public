# Uppgradera ett projekt från ny mallversion

1. Läs projektets sparade mallversion, profil, beslut och lokala avvikelser.
2. Jämför ny mallversion mot föregående med en läsbar diff och klassificera varje ändring som säker, konflikterande eller ej tillämplig.
3. Applicera bara säker och avsiktligt godkänd ändring; skriv aldrig över projektspecifika beslut, hemligheter, miljövariabler eller driftkonfiguration.
4. Kör relevanta kontroller och dokumentera resultat samt den nya mallversionen i projektprofilen.
5. Skapa ett beslut- eller tekniskt ärende för varje konflikt eller uppskjuten uppgradering.

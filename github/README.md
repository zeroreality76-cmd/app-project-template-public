# GitHub-underlag

Denna katalog förbereder en GitHub-modell men skapar, ändrar eller aktiverar ingenting externt.

1. Genomför [setup-checken](../docs/operations/SETUP_CHECK.md).
2. Kontrollera ägare, repo, plan, behörighet och abonnemangsbegränsningar.
3. Konfigurera labels, milestones och Projects V2 enligt detta underlag.
4. Kopiera endast godkända workflowmallar från `automation/workflows-inactive/` till `.github/workflows/` via en granskad ändring.

Issue forms och PR-mall i `.github/` är versionsbara standardiseringsunderlag; de är inte körande automationer.

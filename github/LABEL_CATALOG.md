# Etikettkatalog

| Grupp | Etiketter | Regel |
|---|---|---|
| Typ | `type:feature`, `type:bug`, `type:technical`, `type:documentation`, `type:risk`, `type:owner-decision` | Exakt en typ per issue. |
| Status | `status:planned`, `status:ready`, `status:in-progress`, `status:blocked`, `status:review`, `status:done` | Projektsvyn ska spegla, inte konkurrera med, operativ status. |
| Prioritet | `priority:p0` till `priority:p3` | P0 kräver dokumenterad incident-/stopphantering. |
| Risk | `risk:security`, `risk:privacy`, `risk:cost`, `risk:delivery` | Kan kombineras med typ och prioritet. |

Skapa katalogen manuellt eller med en senare verifierad API/CLI-rutin. Kontrollera först att etiketten saknas för att undvika dubbletter.

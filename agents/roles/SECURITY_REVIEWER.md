# Roll: Säkerhetsgranskare

**Uppdrag:** granska attackytor och säkerhetsgränser oberoende av builder.

- Fokusera på identitet, behörighet, indata, hemligheter, dataläckage, beroenden och externa gränssnitt.
- Uppdatera hotbedömning med verifierbara kontroller och återstående risk.
- Blockera release vid oacceptabel risk; eskalera riskacceptans till beslutsägaren.

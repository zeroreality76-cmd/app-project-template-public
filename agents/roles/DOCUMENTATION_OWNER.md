# Roll: Dokumentationsansvarig

**Uppdrag:** hålla källstyrd dokumentation sammanhängande och sann.

- Uppdatera endast berörda källdokument enligt dokumentationsmatrisen.
- Kontrollera länkar, motsägelser, föråldrad status och planerat-vs-implementerat språk.
- Skapa åtgärdsärende eller blockera färdigmarkering när obligatorisk dokumentation saknas.
